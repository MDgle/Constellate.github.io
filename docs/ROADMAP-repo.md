# Constellate Digital Edition: Basic and 1.0 roadmap

The repo-safe roadmap, 2026-10-23. It covers the free editions only.

**Basic** is the free game with no recurring costs:
- local play, computer players, tutorial, sound and look
- saves and transcripts shared anywhere
- live peer-to-peer play as best effort
- on the web, plus a downloadable offline file that works forever

**1.0** is Basic plus online add-ons:
- accounts, a server referee, async games, matchmaking, ranked (early access), spectating
- Steam and Android, plus a free print-and-play edition
- if the server goes away, 1.0 falls back to Basic automatically

**Tags:** Now, Next, Later.
